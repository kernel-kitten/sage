# sage
Subject Aware Generative Educational Agent

STEPS TO RUN THIS REPO
- open the terminal and clone the repo using the commnand : git clone https://github.com/kernel-kitten/sage.git
- open vs code
- create a virtual env : python3 -m venv venv
- activate the virtual env : source venv/bin/activate.
- make sure you are on the correct path interpreter
- install requirements.txt : pip install -r requirements.txt
- add your GROQ_API_KEY in the .env file
- run streamlit.py : streamlit run streamlit.py
