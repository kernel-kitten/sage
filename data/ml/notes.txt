# 📘 Simple Plain Notes for Machine Learning

# 1️⃣ What is Machine Learning?

**Machine Learning (ML)** is a field of AI where computers **learn patterns from data and make predictions without being explicitly programmed**.

Example:

* Email spam detection
* Netflix recommendations
* Face recognition
* Stock prediction

Instead of writing rules manually, we **train a model using data**.

---

# 2️⃣ Types of Machine Learning

There are **3 main types**.

## 1. Supervised Learning

Model learns from **labeled data**.

Labeled data = input + correct output.

Example dataset:

| Study Hours | Exam Score |
| ----------- | ---------- |
| 2           | 40         |
| 4           | 60         |
| 6           | 80         |

Model learns relationship.

Tasks:

* **Classification** → predict category
* **Regression** → predict number

Examples:

| Problem                | Type           |
| ---------------------- | -------------- |
| Spam detection         | Classification |
| House price prediction | Regression     |
| Disease detection      | Classification |

---

## 2. Unsupervised Learning

Data has **no labels**.

Model tries to **find patterns or groups**.

Example dataset:

| Height | Weight |
| ------ | ------ |
| 170    | 65     |
| 180    | 80     |
| 150    | 50     |

Algorithm groups similar data.

Common tasks:

| Task                     | Algorithm |
| ------------------------ | --------- |
| Clustering               | K-Means   |
| Dimensionality reduction | PCA       |

Example use:

* Customer segmentation
* Market analysis

---

## 3. Reinforcement Learning

Agent learns by **trial and error**.

Concepts:

| Term        | Meaning  |
| ----------- | -------- |
| Agent       | learner  |
| Environment | world    |
| Action      | decision |
| Reward      | feedback |

Example:

* Self-driving cars
* Game AI (AlphaGo)

# 6️⃣ Overfitting vs Underfitting

## Overfitting

Model learns **training data too well**.

Problem:

* Memorizes data
* Performs poorly on new data

Example:
Training accuracy = 99%
Test accuracy = 60%

---

## Underfitting

Model is **too simple**.

Problem:

* Cannot capture patterns.

Example:
Training accuracy = 60%
Test accuracy = 55%

---

## Ideal Model

```
Good training accuracy
Good test accuracy
```

---

# 7️⃣ Bias vs Variance

Important ML concept.

| Concept  | Meaning           |
| -------- | ----------------- |
| Bias     | model too simple  |
| Variance | model too complex |

Relationship:

```
High Bias → Underfitting
High Variance → Overfitting
```

Goal:

```
Balance bias and variance
```

---

# 8️⃣ Common Machine Learning Algorithms

## Linear Regression

Used for **predicting numbers**.

Example:

```
Predict house price
Predict temperature
Predict salary
```

Simple equation:

```
y = mx + b
```

Where:

* y → prediction
* x → input
* m → slope
* b → intercept

---

## Logistic Regression

Used for **classification problems**.

Example:

```
Spam or Not Spam
Disease or No Disease
Pass or Fail
```

Output range:

```
0 to 1 probability
```

Example:

```
0.8 → Spam
0.2 → Not Spam
```

---

## Decision Tree

Model makes decisions using **tree structure**.

Example:

```
            Age < 30?
           /        \
        Yes          No
       /              \
   Student?         High Income?
```

Advantages:

* Easy to understand
* Works well with nonlinear data

---

## Random Forest

Random Forest = **many decision trees combined**.

Idea:

```
Multiple trees vote
Final prediction = majority vote
```

Advantages:

* More accurate
* Reduces overfitting

---

## Support Vector Machine (SVM)

SVM finds **best boundary between classes**.

Example:

```
Cats vs Dogs
Spam vs Not Spam
```

Goal:
Find **maximum margin hyperplane**.

---

## K-Nearest Neighbors (KNN)

Prediction based on **nearest neighbors**.

Example:

If **3 nearest neighbors are class A**, prediction = A.

Parameter:

```
K = number of neighbors
```

---

# 9️⃣ Model Evaluation Metrics

## For Classification

| Metric    | Meaning                         |
| --------- | ------------------------------- |
| Accuracy  | correct predictions             |
| Precision | correct positive predictions    |
| Recall    | ability to detect positives     |
| F1-score  | balance of precision and recall |

Confusion Matrix:

|                 | Predicted Positive | Predicted Negative |
| --------------- | ------------------ | ------------------ |
| Actual Positive | TP                 | FN                 |
| Actual Negative | FP                 | TN                 |

---

## For Regression

| Metric | Meaning                 |
| ------ | ----------------------- |
| MAE    | mean absolute error     |
| MSE    | mean squared error      |
| RMSE   | root mean squared error |
| R²     | model fit score         |

---

# 🔟 Gradient Descent

Optimization algorithm used to **train models**.

Goal:

```
Minimize loss function
```

Idea:

```
Take small steps toward minimum error
```

Important parameter:

```
Learning Rate
```

If learning rate is:

* Too high → overshoot
* Too low → slow training

---

# 1️⃣1️⃣ Feature Engineering

Feature engineering = **improving input data**.

Techniques:

| Technique         | Example                       |
| ----------------- | ----------------------------- |
| Normalization     | scale data                    |
| Encoding          | convert categories to numbers |
| Feature selection | choose important features     |

Example:

```
City → One-hot encoding
```

---

# 1️⃣2️⃣ Cross Validation

Used to **evaluate model reliability**.

Common method:

**K-Fold Cross Validation**

Example:

```
Dataset split into 5 parts
Train on 4
Test on 1
Repeat 5 times
```

Final score = average.
